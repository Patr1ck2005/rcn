# Contributing with agents

Read README.md and docs/architecture.md before editing. Keep changes within the public generic platform. Use independent temporary state for tests and demos; never connect tests to a real center.

Scientific templates, runtime archives, solver installations, credentials, live identities and production audit records are outside this repository. Jobs use registered, bounded execution profiles; do not add arbitrary command execution. Preserve machine-owner consent, explicit pause and attempt identities.

Run the related Python and frontend tests. Use scripts/build.py for release builds. Generated assets and distributions are build artifacts, not source commits. Keep original source assets and compact acceptance receipts. Record commit provenance accurately.
