# 0.15.0a5 source preview

[Home](../../README.md) · [Member guide](../member-guide.md) · [Detailed connection guide](../member-onboarding-guide.md)

This source update adds one member flow for installing the client, importing a
private personal connection bundle, and configuring a named Agent. HTTPS and
explicit managed SSH bundles use the same preview, confirmation and recovery
interface. Interrupted imports retain their original operation identifiers.

Each Agent receives an independent restricted credential generated and protected
with Windows CurrentUser DPAPI before registration. Repeated registration keeps
the original UUID, content and current credential state. Revocation affects that
Agent; removing a local login is a separate operation. Codex, Claude Code, DSH and
generic command-capable Agents use the exported credential-free instructions.

Installed Windows clients gain a stable Agent command entry, offline public
Markdown help, context and staged diagnostics. Protected help is authorized by
the current center identity. Diagnostics and recovery preserve original tasks,
results and explicit owner pauses.

The public installer still has no scientific runtime, template, solver or
preapproved archive. Operators must supply their own approved profiles and
runtime configuration. This source change does not publish a release artifact or
establish external Windows, elevation, restart, network or scientific acceptance.
