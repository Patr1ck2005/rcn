# 0.15.0a3 — registered result retrieval and storage visibility

This preview adds a metadata-only administrator storage view and retrieval from explicitly registered local archive sources. Member connection restoration, hidden Windows ACL checks and offline task-package help from alpha.2 are retained.

- The storage view separates physical free space, active capacity commitments, the 10 GiB reserve, logical project data, observed physical allocation and confirmed retirement. Partial or stale coverage remains unknown. Native exact-path inventory is bounded and resumable; opening the page does not enumerate directories, read data or probe another host.
- Explicit downloads reuse valid local files or read a registered source through the existing result-preparation and Range transport. Results go directly to the requester's destination. Browsing does not move data; intentionally retired models are not recomputed.
- The member queue deduplicates downloads for the same target, uses FIFO admission and one timer for actual retry deadlines, and retains pause/operation identity. Dispatcher sorting reads personal policy once per distinct user in a round.
- Runtime version reporting comes from the package's own distribution metadata. Wheel construction and release preparation reject disagreement between runtime, API, build identity and distribution versions.

Registration requires an operator-provided source adapter, original custody and manifest evidence, current physical storage identity and exact relative file maps. This release does not discover arbitrary member archives. Scientific profiles, solver runtimes, licenses and project data remain external inputs.

See [source/transport interfaces](../storage-algorithm-interfaces.md), [measurement evidence and its limitations](../storage-algorithm-verification.md), [member guide](../member-guide.md), [offline task-package tutorial](../member-task-package-guide.zh.md) and [artifact parity contract](../public-export.md). Release assets include the client Setup, its companion runtime ZIP, manifests and checksums. Content hashes establish integrity, not a publisher signature.

External clean-machine Windows, distinct standard/admin users, UAC/reboot and another lab's scientific execution remain deferred. Isolated tests and fixtures do not stand in for those trials. No production stress jobs are part of this release.
