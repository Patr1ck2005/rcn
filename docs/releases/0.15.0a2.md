# 0.15.0a2 — member connection and release consistency

This preview integrates the member fixes that had remained on a separate development branch:

- Background Windows ACL checks run without creating console windows. A single request reuses its verified connection descriptor, while each new request still validates the current identity and transport.
- Managed SSH connections reuse their owned tunnel and retain the original member identity. HTTPS remains the public default.
- Task-package preparation help is available from the actual member submission page, including before login or while the center is offline. The CLI and project-side preparation contract remain explicit.
- Release parity checks compare shared source and actual wheel/installer contents. Scientific assets, production configuration and credentials remain excluded from public packages.
- Existing production fixes to dispatcher lease renewal, recovery write-lock duration and large-result copy timeout are retained.

The installer does not include COMSOL or a scientific runtime. Existing owner pauses, task identities, priorities and results are not reset by an upgrade. External clean Windows, UAC, reboot, real HTTPS onboarding and a new member's scientific end-to-end trial remain separate acceptance work. Synthetic browser and isolated software tests do not claim those trials passed.

See the [member task-package guide](../member-task-package-guide.zh.md) and [release export contract](../public-export.md). Artifact hashes and exact validation results accompany the GitHub release.
