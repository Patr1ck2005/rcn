# 0.15.0a1 — Public preview

Release date: 2026-10-20. [Home](../../README.md)

This is the first public preview of RCN's generic coordination and member-tool source, extracted into a separate repository from a privately operated research system. It is an alpha release; interfaces and deployment packaging may change before a stable public release.

## Included

- Python control plane and typed client contracts.
- Planning, resource/policy placement, scheduling, dispatcher, and recovery machinery.
- Machine supervision, runtime approval/admission, and operational audit code.
- React browser console with fleet, job, insights, approval, and member workflows.
- Windows member client and personal Agent CLI.
- A local synthetic fleet demo and practical source-install documentation.

The code has been used in a private research group. Public examples and fixtures use synthetic identities and data. Private production history, operational state, credentials, scientific projects, and group-specific deployment material are not part of this public source history.

## Execution boundary

Scientific execution still needs a separately supplied origin adapter, approved runtime, supported host environment, and any required solver license. This release includes no COMSOL installation, scientific templates/data, or sealed scientific runtime archives. Profile registration alone does not make compute onboarding functional.

The [quickstart](../quickstart.md) exercises the control plane and UI with synthetic data. It does not certify remote execution, an external lab deployment, or scientific correctness. The console currently uses Chinese labels; English UI localization remains future work.

## Preview acceptance

On 2026-10-20, the public source passed 148 Python tests; the installed wheel passed the same 148 tests from site-packages, with the source directory removed from the import path. Frontend unit tests passed 304 cases. Desktop/mobile overview, fleet and runs pages passed six browser checks with synthetic data and no page errors.

A fresh unsigned Windows Setup completed a silent, isolated current-user installation without creating desktop or logon entries. The installed payload passed its file inventory check and served the member login page without browser errors. The public payload contains no scientific archives, models or scientific Python dependency closure. These checks do not establish remote-machine enrollment, UAC/reboot behavior, a new member's scientific trial, or independent lab acceptance.

See the [compact validation receipt](0.15.0a1-validation.json). The Python source and installed checks cover the same regression population, so their counts are not added.
