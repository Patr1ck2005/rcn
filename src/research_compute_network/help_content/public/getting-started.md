# Getting started

The public demo uses synthetic jobs and machines. Run `rcn serve --demo` with an independent `RCN_HOME` and visit `/app/overview` on the selected loopback port.

For a configured group, follow the installed [member guide](/help/member-getting-started): install Setup, request access at the group's HTTPS address, and wait for the operator to approve the original pairing. Personal login and an independent Agent credential are then configured locally. Existing connection bundles and manual HTTPS login remain advanced recovery options. Machine contribution is optional and separately authorized. Scientific executors, models, solver licenses and project runtime packages are provided by the operator.

For task package preparation, see the installed [Agent packaging guide](/help/member-task-package). It remains available when the center is offline.
