# Getting started

The public demo uses synthetic jobs and machines. Run `rcn serve --demo` with an independent `RCN_HOME` and visit `/app/overview` on the selected loopback port.

For a real center, obtain your own personal access token from its administrator. Machine contribution is optional and separately authorized. Scientific executors, models, solver licenses and project runtime packages are provided by the operator.
